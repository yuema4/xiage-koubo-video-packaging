# Video Packaging Style Options

Use one style per task unless the user explicitly asks for a comparison. All four styles are designed to keep readable hierarchy and a safe area around a talking head.

## 1. Capsule 胶囊风

- Visual language: cream paper, Bodoni Moda or Songti display headline, Space Grotesk labels, rounded capsule cards, candy-color pills, 2px dark outlines, soft hard-offset shadows.
- Best for: creator education, AI tool explainers, personal workflows, warm editorial content.
- Motion: pill pop, rounded card slide, staggered tiles, playful but controlled spring.
- Practical impact: friendliest and most approachable; uses more visual personality and softer geometry.

## 2. BlockFrame 新粗野主义

- Visual language: warm white canvas, saturated pastel blocks, 4px black borders, 8px hard black shadows, zero radius, stickers, starbursts, angled rectangles, high density.
- Best for: strong opinions, hot topics, listicles, energetic tutorials, poster-like openings.
- Motion: hard snap, offset slide, sticker slam, strike-through, chunky step reveals.
- Practical impact: strongest visual interruption and scroll-stopping power; can feel loud if every sentence receives a card.

## 3. Tech Glass / Workflow HUD 科技风

- Visual language: dark translucent glass panels, cyan/blue structure lines, restrained orange emphasis, HUD brackets, process nodes, timelines, charts, terminal metadata.
- Best for: AI agents, automation, software features, workflow diagrams, product demonstrations.
- Motion: panel reveal, node activation, process-line draw, metric count-up, chart growth, controlled depth/orbit cards.
- Practical impact: makes the content feel like a product system or operating console; should use one primary module plus one light support module, not a dense sci-fi background.

## 4. Minimal Bar 信息条风

- Visual language: dark translucent horizontal bars, thin lime/orange accent strips, compact English labels, white Chinese typography, very little decoration.
- Best for: talking-head tutorials, interviews, documentary explanations, content where the person must remain dominant.
- Motion: clean bar slide, accent-line sweep, restrained label fade, small status tick.
- Practical impact: clearest and least distracting; conveys less visual drama but preserves the most source-video presence.

## Selection prompt

When style is missing, ask:

```text
请选择这次的视频包装风格：
1. Capsule 胶囊风：亲和、编辑感、糖果色胶囊卡片
2. BlockFrame 新粗野主义：粗黑边框、硬阴影、强冲击海报感
3. Tech Glass / Workflow HUD：科技玻璃、流程节点、AI 产品感
4. Minimal Bar 信息条：克制、清晰、最大程度保留真人主体
```
